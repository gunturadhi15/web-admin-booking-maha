SANGAT PENTING: JANGAN MERUBAH TAMPILAN UI, TEMA (DARK THEME UNTUNG USAHA), STRUKTUR KOMPONEN, ATAU TATA LETAK SAMA SEKALI. 

Tugas utama Anda HANYA menghubungkan data backend/database (Supabase) ke dalam state dan fungsi yang SUDAH ADA di web admin ini.

Instruksi Detail Integrasi:

1. Setup Supabase Client:
   - Pasang/konfigurasi `@supabase/supabase-js` menggunakan Environment Variables:
     - `NEXT_PUBLIC_SUPABASE_URL`
     - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   - Pastikan variabel ini sama persis dengan yang dipakai di Web Booking.

2. Hubungkan Data Real (Replacing Mock/Dummy Data):
   - Jangan ubah struktur state atau interface data pesanan/statistiks yang sudah dipakai oleh UI saat ini.
   - Sambungkan fungsi fetching data Supabase dari tabel `bookings` untuk mengisi state/data yang ditampilkan pada:
     - Card Stat "Pendapatan Hari Ini", "Total Pesanan Aktif", "Laba Bersih", dll.
     - Tabel / List "Pesanan Terbaru" (Kode, Pelanggan, Layanan, Total).
     - Menu "Kelola Pesanan", "Data Pelanggan", dan status rekap usaha.

3. Fitur Supabase Realtime Subscription:
   - Tambahkan pendengar data real-time (`postgres_changes`) pada tabel `bookings`.
   - Ketika ada pesanan baru yang masuk dari Web Booking, perbarui state lokal secara langsung agar UI otomatis ter-update secara otomatis TANPA me-refresh halaman atau merubah tampilan layout.

4. Aksi CRUD (Tanpa Merubah Flow Form/Modal UI):
   - Hubungkan tombol/fungsi aksi yang sudah ada di UI (seperti Ubah Status Pesanan, Selesaikan Pesan, Tambah Pesanan Baru, atau Hapus) langsung ke query Supabase (`update`, `insert`, `delete`).
   - Pertahankan semua penanganan modal, dialog, dan notification toast yang sudah terpasang di UI Untung Usaha.

Mohon berikan kode penyesuaian (misalnya pada custom hook, service layer, atau file state utama) tanpa mengubah file komponen UI pendukung.
